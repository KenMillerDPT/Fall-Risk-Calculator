How to use Patient Medication Review Enter each medication on a separate line — generic names, brand names, or drug classes all work.

The tool will:
✓ Check every drug against the full 2023 Beers Criteria
✓ Calculate the patient's Anticholinergic Burden Score
✓ Flag dangerous drug–drug interactions (Table 5)
✓ Generate a printable one-page clinical summary

Tips:
• Use Enter between each drug
• Brand names work: Ambien → Zolpidem
• Drug classes work: benzodiazepine
• Add patient name/age for the printed report header
